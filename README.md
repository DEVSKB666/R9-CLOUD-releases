# R9-CLOUD

ดาวน์โหลดแอป R9-CLOUD ได้จากหน้า [Releases](https://github.com/DEVSKB666/R9-CLOUD-releases/releases/latest)

## macOS (Apple Silicon และ Intel)
1. ดาวน์โหลดไฟล์ `.dmg` แล้วลาก **R9-CLOUD** ไปไว้ใน Applications
2. ครั้งแรกให้คลิกขวาที่แอป แล้วเลือก **Open** เพราะแอปยังไม่ได้เซ็นด้วย Apple Developer ID
3. ถ้า macOS แจ้งว่าแอปเสีย ให้เปิด Terminal แล้วรัน:
   `xattr -dr com.apple.quarantine "/Applications/R9-CLOUD.app"`

## Windows 10/11
1. ดาวน์โหลดไฟล์ `-setup.exe` แล้วติดตั้ง
2. ถ้า SmartScreen เตือน ให้กด **More info** แล้วเลือก **Run anyway**

แอปจะอัปเดตตัวเองอัตโนมัติเมื่อมีเวอร์ชันใหม่
